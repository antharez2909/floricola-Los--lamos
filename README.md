# floricola-Los-Alamos

Descripción de la aplicación

Florícola Los Álamos es una aplicación digital pensada para apoyar la gestión y venta de productos de una florícola. Permite a los clientes consultar el catálogo, crear una cuenta, agregar productos al carrito, realizar pedidos, enviar comprobantes de pago por transferencia y revisar el historial de sus compras. Los pedidos se coordinan para retiro presencial en la florícola.

La aplicación también cuenta con funciones administrativas para gestionar productos, clientes, pedidos y la revisión de pagos. Está desarrollada con Flutter, con una API en Flask y una base de datos MySQL. El proyecto contempla su uso en Flutter Web y Android.

En su proceso de desarrollo se utilizaron herramientas de inteligencia artificial como apoyo en aproximadamente un 50 % del trabajo. La IA sirvió como herramienta de asistencia; las decisiones, ajustes e integración de la aplicación forman parte del desarrollo del proyecto. Ese porcentaje describe el proceso de creación, no significa que la aplicación tenga funciones de inteligencia artificial.

La aplicación es una base funcional para un emprendimiento y podrá seguir mejorando mediante futuras actualizaciones. Entre las mejoras posibles están optimizar la experiencia de compra, incorporar nuevos medios de pago, añadir reportes de ventas y adaptar el sistema a las necesidades que surjan con el crecimiento del negocio.
